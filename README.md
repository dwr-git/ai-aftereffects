# AI Анимация

Моушн-дизайн и композитинг в браузере: композиции, слои, ключевые кадры, эффекты, выражения,
3D-камеры и свет, очередь рендеринга — и помощник с ИИ на панели справа. Работает на вашем сервере
(nginx + PHP 8) без интернета: модель для помощника берётся из `.env` системы.

- Как поставить на сервер и настроить: [`studio/README.ru.md`](studio/README.ru.md)
- Что нового: [`studio/CHANGES.ru.md`](studio/CHANGES.ru.md)
- Готовые сборки: раздел Releases (zip с папкой для сервера)

Основан на [EffectCraft](https://github.com/storytold/effectcraft) от команды ArtCraft
(MIT OR Apache-2.0); его исходное описание — в [`docs/README-upstream.md`](docs/README-upstream.md).
Знаки ArtCraft из этой версии удалены, как требует их лицензия.

After Effects — товарный знак компании Adobe. AI Анимация не связана с Adobe и открывает проекты в форматах
After Effects (.aep, .aepx).
